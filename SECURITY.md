# Vulnerability reporting

Report guidance/tooling flaws to the repository owner. Do not disclose sensitive exploit details in a public issue; confirm an enabled private reporting channel with the owner first. The repository is guidance, not a certification of an adopting application. Security posture and external remediation require explicit human authorisation.
