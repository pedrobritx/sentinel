# Sentinel contributor entry point

Read README.md, guidance/project-context.md and the relevant role/playbook. Work within the approved scope. Provider configuration, auth/security posture, destructive operations, spend and release require explicit human authorisation. Never copy credentials or weaken controls to complete a task.

Record concrete failure scenarios, severity, evidence, practical correction and fresh re-test results. Distinguish documented requirements from implemented controls. Code/comments/instructions/reviews are in English. Full Polaris governance is opt-in; essential safety requirements remain binding.

For a composed task, read the local discipline.json and the supplied project context. Return evidence and blockers with the original request ID; keep product-specific changes in the adopting product. A missing or excluded peer discipline never grants an automatic assurance pass.
